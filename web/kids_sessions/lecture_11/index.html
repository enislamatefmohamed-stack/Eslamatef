الشروط واتخاذ القرار (If / Else)

كيف نجعل الحاسوب يختار بذكاء بين مسارات مختلفة كالقائد الحكيم؟

❓

الشرط (Condition)

سؤال حاسم إجابته إما نعم (True) أو لا (False)

⚡

القرار (Action)

الأمر الذي ينفذه الكود بناءً على نتيجة الفحص

المفهوم الأساسي الشرط البرمجي

ما هو الشرط البرمجي؟ ❓

الشرط هو اختبار يجريه المعالج للتأكد من حالة معينة قبل تنفيذ أي خطوة تالية.

✅

صحيح (True = 1)

الشرط تحقق بنجاح! يتم تشغيل الأوامر التابعة له فوراً.

❌

خاطئ (False = 0)

الشرط لم يتحقق! يتم تجاهل الأوامر أو الانتقال للبديل.

💡 تذكر: الحاسوب لا يعرف كلمة "ربما" أو "في الغالب"! العالم الرقمي إما 0 أو 1.
القاعدة الأولى لو ... إذن (If ... Then)

جملة الشرط البسيطة (If Then) 🌟

نخبر البرنامج: "إذا حدث هذا الأمر فقط... نفذ هذا الإجراء".

بايثون / Python if score > 50:
    print("مبروك يا بطل.. أنت ناجح! 🎉")
🔍

ماذا يحدث لو النتيجة 40؟

الشرط خاطئ (False)، سيتجاهل الكمبيوتر أمر الطباعة ويكمل ما بعده دون إحداث أي تغيير!

القاعدة الثانية لو ... وإلا (If ... Else)

الشرط والبديل: خطة لكل سيناريو 🔀

تحديد مسارين واضحين: مسار عند النجاح، ومسار بديل عند الفشل.

Python Code if weather == "rainy":
    take_umbrella()  # مسار المطر ☔
else:
    wear_sunglasses() # مسار الشمسية 😎
☔

إذا نعم (If True)

يأخذ الطفل المظلة

😎

إذا لا (Else)

يرتدي الطفل النظارة الشمسية

ربط بالواقع أمثلة يومية

أين نجد الشروط في حياتنا اليومية؟ 🌍

⏰

منبه الاستيقاظ

لو الساعة 7:00 ص ➡️ شغل رنين المنبه، وإلا خليك صامت.

🔋

شحن الهاتف

لو البطارية 100% ➡️ اعرض ضوء أخضر، وإلا ضوء برتقالي.

🚪

باب المول الأوتوماتيكي

لو مستشعر الحركة حس بشخص ➡️ افتح الباب، وإلا اغلقه.

أساس علم الحاسوب Boolean Logic

جورج بول وسر المتغير المنطقي (Boolean) 💡

نوع خاص من البيانات يقبل قيمتين فقط لا غير:

1️⃣ 🟢

True (صحيح)

يمثل وجود تيار كهربائي، تحقق الشرط، والموافقة على التنفيذ.

0️⃣ 🔴

False (خاطئ)

يمثل انقطاع التيار، عدم تحقق الشرط، والتخطي للمسار الآخر.

"من أبسط معادلات نعم ولا.. بُنيت أعظم حواسيب العالم وخوارزميات الذكاء الاصطناعي!"

أدوات المقارنة الأكبر والأصغر

أدوات المقارنة الرياضية: الأكبر والأصغر ⚖️

📈

أكبر من (>) وأكبر من أو يساوي (>=)

مثل فحص سرعة السيارة: if speed > 120:
إطلاق إنذار السرعة الزائدة!

📉

أصغر من (<) وأصغر من أو يساوي (<=)

مثل فحص شحن البطارية: if battery < 20:
تفعيل وضع توفير الطاقة فوراً!

سر المبرمجين المطابقة (==)

سر علامتي التساوي (== vs =) 🧐

علامة واحدة: [ = ]

تخزين وتعيين (Assignment)

ضع هذه القيمة داخل الصندوق.
x = 5 (اجعل x تساوي 5)

علامتان: [ == ]

فحص ومقارنة (Comparison)

هل القيمتان متساويتان حقاً؟
if x == 5: (هل x تساوي 5؟)

⚠️ احذر: كتابة علامة واحدة داخل جملة if تسبب خطأً شهيراً في البرمجة!
أدوات المقارنة الاختلاف (!=)

علامة عدم التساوي: ليس مساوياً (!=) 🚫

علامة التعجب [ ! ] في عالم البرمجة تعني النفي (NOT).

Python if player_status != "banned":
    allow_game_access() # اسمح له باللعب مع أصدقائه

تفسير الكود:

إذا كانت حالة اللاعب "لا تساوي" محظور.. اسمح له بالدخول. أما إذا كان محظوراً، امنعه فوراً!

تعدد الاختيارات Elif / Else If

الشروط المتعددة: أكثر من خيارين! 🪜

عندما تكون هناك احتمالات كثيرة، نستخدم (elif) للترتيب الهرمي.

Python Grading System if score >= 90:

elif score >= 70:

else:
    grade = "يحتاج للمذاكرة 📚"

المنطق المركب النفي (NOT)

أداة القلب والنفي: (NOT / ليس) 🔄

تقلب الصواب خطأً والخطأ صواباً (عكس القيمة تماماً).

not True ➡️ False

إذا لم تكن الحقيقة صواباً فهي خطأ

not False ➡️ True

إذا لم يكن الأمر خاطئاً فهو صحيح
