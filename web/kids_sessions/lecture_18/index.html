Scratch i-Frames Script set [is_invincible v] to [True]
repeat (4) {
    set [ghost v] effect to (60)  // وميض شبه شفاف 👻

مقارنة فنية Color vs Sprite

متى نستخدم استشعار الكائن ومتى نستخدم اللون؟ 🎨👾

استشعار الكائن (touching Sprite)

  • أسرع وأخف على معالج الكمبيوتر
  • لا يتأثر بتغيير إضاءة أو لون الكائن
  • مثالي للأعداء، العملات، المقذوفات، والأبواب

استشعار اللون (touching Color)

  • رائع لتحديد أجزاء معينة (أقدام البطل فقط)
  • رائع لفحص بيئة المسرح (عشب أخضر، ماء أزرق، لافا حمراء)
  • يحتاج دقة مطابقة كود اللون بالضبط بقطارة الألوان

المصممون المحترفون يجعلون صندوق التصادم الفعلي محصوراً في قلب جسم البطل (Torso). هذا يمنح اللاعب شعوراً بالراحة ويجعله ينجو في اللحظات الأخيرة بشق الأنفس، مما يزيد الإثارة بنسبة 1000%!
