المفهوم الأساسي حلقة التكرار (Loop)

ما هي حلقة التكرار (Loop)؟ 🔁

أمر برمجي يطلب من المعالج إعادة تنفيذ مجموعة تعليمات مراراً وتكراراً حتى يتحقق هدف معين.

💡

بدون حلقات التكرار:

لكتابة كلمة 100 مرة، سنحتاج لكتابة 100 سطر طباعة مكرر!

باستخدام حلقة التكرار:

نكتب سطرين فقط: for i in range(100): print("أحب البرمجة!")

شعار المبرمجين Don't Repeat Yourself

مبدأ المبرمجين الأذكياء: (DRY) 🛡️

Don't Repeat Yourself = إياك أن تكرر كتابة الكود يدوياً!

❌ كود مكرر يدوي (WET)

We Enjoy Typing (نضيع وقتنا في الكتابة)

  • كود طويل وصعب القراءة
  • لو أردنا تعديل كلمة سنعدلها في 100 مكان!
  • احتمال حدوث أخطاء إملائية كبير

✅ كود نظيف أنيق (DRY)

Don't Repeat Yourself (كود ذكي ومختصر)

  • كود قصير يسهل فهمه وصيانته
  • التعديل في سطر واحد يغير كل شيء فوراً
  • أسرع وأخف في استهلاك الذاكرة

النوع الثاني While Loop

التكرار المشروط: طالما الشرط مستمر! (While Loop) ⏳

لا نعرف عدد المرات بالضبط، لكننا نستمر بالتكرار طالما الشرط صحيح (True).

Python while battery_level > 10:
    play_game()
    battery_level -= 1 # البطارية تنقص مع اللعب
🎮

طالما البطارية > 10

استمر في الاستمتاع باللعبة والتحدي

🔌

عندما تصل البطارية إلى 10

تتوقف الحلقة فوراً ويطلب الجهاز الشحن

صمام الأمان Stopping Condition

شرط التوقف: بوابة الخروج الآمنة 🛑

كل حلقة تكرار يجب أن تمتلك وسيلة للخروج والانتهاء عندما يكتمل الهدف.

🟢

أثناء استمرار الشرط

الشرط = True ➡️ المعالج ينفذ الأوامر ويعيد الدوران لأعلى الحلقة.

🔴

لحظة تحقق التوقف

الشرط = False ➡️ المعالج يقفز خارج الحلقة فوراً ويكمل بقية البرنامج.

النوع الثالث Forever Loop

الحلقة اللانهائية: تدور إلى الأبد! ♾️

حلقة لا تحتوي على شرط توقف مسبق، أو شرطها دائماً True.

برمجة سكراتش Forever

مكعب (كرر باستمرار - Forever) ♾️

البلوك الذي يجعل شخصيتك حية وذكية طوال فترة تشغيل اللعبة!

Scratch Block Logic forever {
    point towards [mouse-pointer v]
    move (3) steps
    next costume
} // القطة تلاحق الماوس وتتحرك رجلاها باستمرار
لاحظ: بلوك Forever أملس من الأسفل ولا يقبل تركيب مكعب تحته لأنه لن ينتهي أبداً!
برمجة سكراتش Repeat Until

مكعب (كرر حتى - Repeat Until) 🛑

تكرار ذكي يستمر حتى يتحقق حدث أو شرط استثنائي في اللعبة.

تطبيق في ألعاب المنصات

القفز والجاذبية:

repeat until <touching [Ground v]?> {
    change y by (-5) // اللاعب يسقط نحو الأرض
}
play sound [land.mp3 v] // عند لمس الأرض يخرج من الحلقة ويصدر صوت الهبوط

لغة بايثون For Loop in Python

حلقة For في لغة بايثون الحقيقية 🐍

أناقة لغة بايثون تجعل كتابة التكرار كأنك تتحدث الإنجليزية!

Python for i in range(5):
    print(f"الصاروخ ينطلق بعد {{5 - i}} ثوانٍ.. 🚀")
print("انطـــــلاق! 🔥")
💡

دالة range(5):

تولد سلسلة الأرقام: [0, 1, 2, 3, 4] وتجعل الحلقة تلف 5 مرات بدقة تامة.

لغة بايثون While Loop in Python

حلقة While في لغة بايثون 🐍

الحلقة الحارسة التي تنتظر تغيراً في حالة البرنامج.

Python coins = 0
while coins < 3:
    print("اجمع عملة ذهبية جديدة.. 🪙")
    coins += 1
print("أحسنت! فتحت الصندوق السري 🎁")
التحكم المتقدم الكسر والخروج (Break)

فرامل الطوارئ: أمر الكسر (Break) 🚨

إنهاء الحلقة فوراً والقفز خارجها عند العثور على المطلوب.

Python Search for chest in treasure_chests:
    if chest.has_diamond():
        print("وجدت الألماسة النادرة! 💎")
        break # توقف عن فتح باقي الصناديق فوراً!
التحكم المتقدم التخطي (Continue)

أمر التخطي السريع: (Continue) ⏭️

تخطي الدورة الحالية فقط والانتقال مباشرة للدورة التالية بدون إيقاف الحلقة.

Python for num in range(1, 6):
    if num == 3:
        continue # طنش الرقم 3 ولا تطبعه
    print(num)
# النتيجة المطبوعة: 1, 2, 4, 5
منطق متقدم حلقة داخل حلقة

الحلقات المتداخلة: حلقة داخل حلقة! 🪆

في كل لفة واحدة للحلقة الخارجية.. تدور الحلقة الداخلية كل دوراتها بالكامل!

🏁

رقعة الشطرنج

حلقة خارجية لتكرار الصفوف الـ 8، وحلقة داخلية لتكرار الأعمدة الـ 8 لرسم 64 مربعاً.

🧮

جدول الضرب

حلقة لتكرار الأعداد من 1 إلى 10، وحلقة داخلية لضرب كل عدد في باقي الأعداد.

فخ المبرمجين كارثة التجمد (Crash)

كارثة التجمد: الحلقة اللانهائية غير المقصودة! ⚠️

❌ كود يسبب تهنيج الجهاز

i = 1
while i < 5:
    print("مرحبا")
    # نسينا نكتب i = i + 1 !

ستظل قيمة i دائماً 1، وسيطبع مرحباً إلى الأبد حتى يتجمد الجهاز!

✅ كود آمن وسليم

i = 1
while i < 5:
    print("مرحبا")
    i += 1 # العداد يزيد في كل لفة

يطبع مرحباً 4 مرات ثم تتوقف الحلقة بسلام!
