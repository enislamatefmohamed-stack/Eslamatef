صناديق المتغيرات (Variables)

كيف تحفظ نتيجتك، اسمك، وعدد نقاطك داخل عقل الحاسوب؟

🏷️

اسم الصندوق (Name)

المسمى المميز الذي ننادي به المتغير في الكود

💎

محتوى الصندوق (Value)

البيانات الحقيقية المحفوظة داخله وتتغير مع الوقت

المفهوم الأساسي ما هو المتغير؟

ما هو المتغير البرمجي؟ 📦

مساحة تخزين محجوزة داخل ذاكرة الكمبيوتر (RAM) لحفظ معلومة نحتاجها أثناء تشغيل البرنامج.

💡

تشبيه صندوق الألعاب:

مثل صندوق ألعابك الملون، تضع عليه ملصقاً من الخارج (الاسم)، وتضع بداخله اللعبة (القيمة). وعندما تشاء، تخرج اللعبة وتضع لعبة جديدة مكانها!

تركيب المتغير Name & Value

أجزاء المتغير الثلاثة 🔍

🏷️

1. اسم المتغير (Identifier)

مثل score أو player_name

📥

2. نوع البيانات (Data Type)

رقم، نص، أم قيمة منطقية؟

💎

3. القيمة (Value)

مثل 100 أو "فرح"

السر اللغوي Variable = قابل للتغير

لماذا سميناه "متغيراً"؟ 🔀

لأن القيمة المحفوظة في الصندوق ليست ثابتة، بل تتغير وتتجدد طوال تشغيل اللعبة!

بداية اللعبةscore = 0
➡️
جمع عملة ذهبيةscore = 10
➡️
فتح صندوق الكنزscore = 100
اسم الصندوق يظل كما هو (score)، بينما القيمة في الداخل تتغير مع كل إنجاز للبطل!
الأمر البرمجي التعيين (Assignment)

عملية التعيين: ضع القيمة في الصندوق! 📥

علامة يساوي الواحدة [ = ] تعني: خذ ما على اليمين وضعه في الصندوق على اليسار.

Python player_name = "سيف"
player_lives = 3
is_winner = False

اسم الصندوق الذي سيستقبل القيمة

الطرف الأيمن

القيمة المراد تخزينها داخل الصندوق

أنواع البيانات 1 الأرقام الصحيحة (Integer)

الأرقام الصحيحة (Integers - int) 🔢

أرقام كاملة لا تحتوي على فواصل أو أجزاء كسرية (موجبة، سالبة، أو صفر).

🎯

النقاط في اللعبة

points = 250
🎂

عمر اللاعب

age = 11

عدد المحاولات

أنواع البيانات 2 الأرقام العشرية (Float)

الأرقام العشرية (Floating Point - float) 📏

أرقام دقيقة تحتوي على علامة عشرية (نقطة .)، للقياسات والسرعات.

🧍

طول اللاعب

height = 1.45
🏎️

سرعة السيارة

speed = 120.8
⏱️

الوقت المتبقي

أنواع البيانات 3 النصوص (String)

النصوص والكلمات (Strings - str) 🔤

سلسلة من الحروف والرموز والمسافات مخصصة للنصوص والقراءة.

✨

القاعدة السحرية للنصوص:

يجب دائماً أن نحيط النص بعلامتي تنصيص " " أو ' ' حتى يفهم الكمبيوتر أنها حروف للعرض وليست أوامر برمجية!

hero_name = "الفارس الذهبي"
welcome_message = "مرحباً بك في عالم المغامرة!"
سر المبرمجين رقم أم نص؟

سر الفرق بين [ 5 ] و [ "5" ] 🧐

الرقم: 5 (Integer)

رقم رياضي حقيقي للعمليات الحسابية.

x = 5
y = 5
print(x + y) # الناتج: 10 🧮

النص: "5" (String)

رسمة حرف مكتوب كالمطبوع على ظهر القميص.

a = "5"
b = "5"
print(a + b) # الناتج: "55" 👕
أنواع البيانات 4 المنطقي (Boolean)

القيم المنطقية (Booleans - bool) 🚦

صندوق بسيط جداً، لا يتسع إلا لإحدى قيمتين فقط:

✅

True (صحيح)

is_game_active = True

اللعبة قيد التشغيل، واللاعب على قيد الحياة.

❌

False (خاطئ)

has_key = False

اللاعب لم يعثر على مفتاح الباب السري بعد.

قواعد الكود Naming Rules

القواعد الذهبية لتسمية الصناديق 📜

✅ مسموح وصحيح

  • حروف إنجليزية وأرقام: player1
  • استخدام الشرطة السفلية: super_speed
  • أسماء معبرة عن المحتوى: coin_count

❌ ممنوع ويسبب أخطاء

  • البدء برقم: 1player (خطأ!)
  • ترك مسافات: player name (خطأ!)
  • استخدام رموز خاصة: score$ (خطأ!)
أناقة الكود Naming Styles

كيف ندمج كلمتين بدون مسافة؟ 🐪🐍

🐪

طريقة سنام الجمل (camelCase)

نبدأ بحرف صغير، ونكبر أول حرف في الكلمة التالية مثل سنام الجمل:

playerName
totalScore
carSpeedMax
🐍

طريقة الثعبان (snake_case)

نربط الكلمات بشرطة سفلية [ _ ] وهي الطريقة المفضلة في بايثون:

player_name
total_score
car_speed_max
تعديل القيمة Updating

تحديث القيمة: كيف تزيد النقاط؟ 📈

المتغير يستعين بقيمته القديمة ليحسب قيمته الجديدة.

Python score = 100
# البطل جمع جوهرة نادرة قيمتها 50 نقطة:
score = score + 50
# أو باختصار: score += 50
print(score) # القيمة الجديدة أصبحت 150!

برمجة سكراتش Scratch Variables

قسم المتغيرات في سكراتش (Variables) 🟧

القسم ذو اللون البرتقالي الداكن المخصص لإنشاء وإدارة الصناديق.

➕

زر (Make a Variable)

تضغط عليه لكتابة اسم الصندوق الجديد واختيار ظهوره للكائنات.

👁️

مربع الاختيار (Checkbox)

لتحديد هل تظهر النتيجة في أعلى الشاشة للاعب أم تظل مخفية في الكواليس.

سكراتش للأطفال Set Variable

مكعب (اجعل المتغير مساوياً لـ - Set to) 🎯

البلوك المسؤول عن تحديد القيمة الابتدائية عند بداية اللعبة.

Scratch Setup Block when green flag clicked
set [score v] to (0)       // تصفير النتيجة
set [lives v] to (3)       // إعطاء 3 محاولات للبطل
set [player_name v] to [نور] // حفظ اسم اللاعب
سكراتش للأطفال Change Variable

مكعب (غيّر المتغير بمقدار - Change by) ➕➖

البلوك السحري لزيادة أو إنقاص الأرقام أثناء اللعب التفاعلي.

🪙

الزيادة الموجبة (+1)

change [score v] by (1)

عند جمع نجمة أو قتل وحش أو إجابة سؤال صحيح.

💔

الإنقاص السالب (-1)

change [lives v] by (-1)

عند الاصطدام بشوكة أو السقوط في الماء أو الخطأ.

واجهة اللعبة Show & Hide

إظهار وإخفاء المتغير على الشاشة 👁️🙈

📢

أظهر المتغير (show variable)

لعرض النتيجة، العداد، وعدد الجواهر أمام عيني اللاعب أثناء اللعب.

🤫

أخف المتغير (hide variable)

لإخفاء الحسابات السرية، إحداثيات الأعداء، أو إخفاء العداد في شاشة النهاية.

صناديق مقفولة الثوابت (Constants)

الثوابت: صناديق بقفل حديدي! 🔒

قيم لا يُسمح بتعديلها أبداً طوال حياة البرنامج لأنها حقائق كونية ثابتة.

📅

أيام الأسبوع

DAYS_IN_WEEK = 7
🥧

النسبة التقريبية باي

PI = 3.14159
⚡

سرعة الضوء

SPEED_OF_LIGHT = 300000
عادة يكتب المبرمجون أسماء الثوابت بحروف كبيرة بالكامل (CAPITAL LETTERS) لتمييزها فوراً!
فخ المبرمجين TypeError

فخ المبتدئين: خلط النص مع الرقم! ⚠️

❌ كود يسبب خطأ فورياً

age = 10
print("عمري هو: " + age)

خطأ: لا يمكن جمع نص مع رقم بالجمع العادي!

✅ الحل السليم في بايثون

age = 10
print(f"عمري هو: {{age}} سنة 🎉")

استخدام نصوص التنسيق (f-strings) يعرض النص والرقم بسلام تام!

Python Dynamic Typing hero = "سوبر سبارك"   # بايثون يفهم أنه String

can_laser = True        # بايثون يفهم أنه Boolean
