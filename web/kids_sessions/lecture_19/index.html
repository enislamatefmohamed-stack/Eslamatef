السباق ضد الزمن Countdown Timer

المؤقت التنازلي: السباق الأسطوري ضد عقارب الساعة! ⏳🏃‍♂️

كيف نبرمج عداد ثوانٍ ينقص بدقة تامة كل ثانية حقيقية؟

Scratch Timer Script when green flag clicked
set [timer v] to (60)            // تحديد 60 ثانية للمرحلة ⏱️
repeat until <(timer) == (0)> {
    wait (1) seconds             // انتظر ثانية كاملة مطابقة للساعة 🕰️
    change [timer v] by (-1)       // انقص ثانية واحدة ⬇️
}
broadcast [TimeIsUp v]           // انطلاق جرس نهاية الوقت! 🚨
فخ المبتدئين Timer Flash Bug

فخ انتهاء الـ 60 ثانية في كسر من الثانية! ⚠️⚡

❌ كود معطوب بدون انتظار

repeat until <timer == 0> {
    change timer by (-1)
}

المعالج ينفذ الحلقة 60 مرة في جزء من الألف من الثانية، فتنتهي اللعبة فوراً دون أن يبدأ اللاعب!

✅ كود سليم بمهلة ثانية

repeat until <timer == 0> {
    wait (1) seconds  <-- الصمام!
    change timer by (-1)
}

ينقص كل ثانية حقيقية بالتطابق التام مع ساعة اليد!

مقارنة فنية Timer Types

المؤقت المخصص مقابل مؤقت سكراتش المدمج ⏱️🆚

المؤقت المدمج في سكراتش (timer)

  • يعد للأعلى فقط (0, 1, 2, 3...)
  • لا يمكن تغيير بدايته أو إضافة ثوانٍ له
  • يستخدم فقط بأمر reset timer

متغير المؤقت المخصص (Custom Variable)

  • تحدد بدايته بحرية (30 أو 60 أو 100)
  • يمكن إضافة ثوانٍ كمكافأة (+5s)
  • يمكن إيقافه مؤقتاً عند محادثة الشخصيات
  • الخيار الاحترافي الأول لمطوري الألعاب!
لحظة الحسم Time's Up!

لحظة انتهاء الوقت (Time's Up Event) 🚨⏰

🛑

1. إيقاف الحركة

تجميد حركة البطل والوحوش فوراً لمنع أي تفاعلات إضافية.

📢

2. صوت الإنذار

تشغيل نغمة جرس الساعة الصاخبة أو نغمة الخسارة الحزينة.

🖼️

3. شاشة النهاية

ظهور شاشة حمراء كتب عليها (انتهى الوقت! حاول مجدداً).

مكافآت النجاة Bonus Time (+5s)

مفاجأة الوقت الإضافي: النجاة في آخر ثانية! ⏳➕✨

أيقونة ساعة رملية في منتصف المرحلة تعطي البطل 5 ثوانٍ ثمينة لإكمال المهمة.

Scratch Bonus Time Script when green flag clicked
show
forever {
    if <touching [Hero v]?> then {
        play sound [clock_bell.mp3 v]  // رنين ساعة مبهج 🎵
        change [timer v] by (5)         // زيادة 5 ثوانٍ إضافية فوراً! ⏳✨
        hide
    }
}

فن التصميم Timer Balance

موازنة التوقيت: كم ثانية تحتاج مرحلتك حقاً؟ ⏱️⚖️

1. وقت المطور الخبير

العب مرحلتك بنفسك واحسب الوقت بالثواني (مثلاً 25 ثانية).

2. قاعدة الـ 1.5X

اضرب وقتك في 1.5 لتعطي وقتاً للاعب الجديد (25 × 1.5 = 37 ثانية).

3. التوقيت الذهبي للمرحلة

اجعل المؤقت 40 ثانية لتحصل على التوازن المثالي بين المتعة والضغط الحماسي!
